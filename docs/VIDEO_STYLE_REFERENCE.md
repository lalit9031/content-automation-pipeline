# Video Style Direction

Reference reviewed on May 26, 2026:
[System Design Part 2 | Requirements Gathering](https://youtu.be/Vhm4qJnAOKY).
The topic is not an editorial input; only its presentation language guides this
video format.

## Reusable Format Observations

- Long-form educational explainer in 16:9 landscape with narrated pacing.
- Dark violet grid background with glowing purple/pink visual depth.
- Orange framed section labels and high-contrast white headline text.
- Illustrated people, simple icons, diagrams, and occasional visual examples
  used instead of footage-heavy editing.
- A chapter structure: intro, problem framing, step-by-step explanation,
  comparisons/examples, and a concluding call to action.
- Text is short and staged as the narration advances; slides support the voice,
  rather than displaying a full paragraph.

## Our Original Template Direction

The pipeline should adopt that instructional motion-graphic format without
copying any reference assets, wording, logos, or exact compositions:

- Purple grid-and-glow branded backdrop.
- Orange topic/section label and clean teaching typography.
- Opening visual, process diagram slides, comparison slides, and closing CTA.
- Motion built from slow zoom, fades, and later per-element entrance animation.
- Narration-first scripting with SRT captions generated from the script.

## Production Additions Needed

1. Expand Prompt Bot output into chapters and short voiceover segments.
2. Generate or source original illustrations/icons for each section.
3. Add voiceover generation or recorded narration and licensed background audio.
4. Export full YouTube 16:9 before deriving vertical Shorts/Reels edits.

Canva remains an optional authoring route for richer animation when eligible
Brand Template Autofill access and a reusable video template are available.
